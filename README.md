# مراسم | MARASEM — منصة الدعوات الرقمية

موقع رئيسي فيه أكثر من قالب دعوة زفاف: أي زائر يختار القالب، يملأ بيانات فرحه،
ويحصل فوراً على **لينك خاص بدعوته** (invite.html?id=MRS-XXXXXX) مع رقم سري
لإدارة دعوته ورؤية تأكيدات الحضور — كل ده ببنية صفرية التكلفة:
واجهة ثابتة (Vercel) + Google Sheets + Google Apps Script.

## الملفات
- `index.html` — الموقع الرئيسي: معرض القوالب (4 قوالب) + نموذج إنشاء دعوة + قسم «إدارة دعوتي»
- `invite.html` — صفحة عرض أي دعوة: تقرأ `?id=كود الدعوة` وتعرض بياناتها بقالبها المختار
  (الظرف الشخصي `?to=اسم الضيف`، عدّاد، معرض، خريطة، RSVP، دفتر تهاني، كارت QR)
- `apps-script/Platform.gs` — الباك إند: تبويبات Invitations / RSVPs / Guestbook
- `manifest.json` + `sw.js` + الأيقونات — دعم PWA للموقع الرئيسي

## القوالب الأربعة
| الكود | الاسم | الطابع |
|---|---|---|
| `royal` | الملكي الذهبي | أخضر غامق × ذهبي شامبين |
| `rose` | الوردي الرومانسي | وردي باستيل × روز جولد |
| `ivory` | العاجي البسيط | أبيض عاجي × أخضر مريمي |
| `night` | الليلي الفاخر | كحلي ليلي × ذهبي |

## الإعداد (مرة واحدة — حوالي 10 دقائق)
1. أنشئ Google Sheet جديد ← Extensions ← Apps Script ← الصق `Platform.gs`
2. شغّل `setupPlatform()` مرة واحدة ووافق على الأذونات (بينشئ التبويبات الثلاثة)
3. Deploy ← Web app ← Execute as: **Me** + Who has access: **Anyone** ← انسخ الرابط
4. Share للشيت: **Anyone with the link — Viewer** (ضروري لقراءة GViz الاحتياطية)
5. في `index.html` و  `invite.html` ضع رابط الـ Web App مكان
   `PUT_YOUR_PLATFORM_APPS_SCRIPT_WEB_APP_URL_HERE`، ومعرّف الشيت (الجزء بين /d/ و /edit)
   مكان `PUT_YOUR_PLATFORM_SHEET_ID_HERE` في invite.html
6. ارفع ملفات الموقع (بدون مجلد apps-script) على مستودع GitHub مربوط بـ Vercel

## ملاحظات تقنية
- كود الدعوة (MRS-XXXXXX) والرقم السري يختارهما/يولّدهما المتصفح عند الإنشاء،
  والرقم السري يُحفظ **مشفّراً (SHA-256)** فقط في الشيت — لا يُحفظ كنص صريح أبداً.
- الإرسال يتم بـ `no-cors` فالواجهة لا تقرأ رد الإنشاء؛ لذلك الكود معروف مسبقاً للعميل.
- بدون ربط الخادم تعمل المنصة في **وضع تجريبي** (localStorage على نفس الجهاز) للتجربة فقط.
- دعوة كريم الأصلية المنفردة (المشروع السابق) لم تُمسّ — دي منصة جديدة مستقلة،
  ويمكن نقل قالبها الملكي كأحد القوالب (وهو فعلاً القالب royal هنا).
